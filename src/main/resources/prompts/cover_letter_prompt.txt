[목적]

내가 여러 개의 경험을 입력하면,

각 경험이 자기소개서 항목(지원동기, 직무역량, 실수 경험, 개선 경험, 협업 경험, 문제 해결 경험, 성격의 장단점, 입사 후 포부 등) 중

어디에 가장 적합한지를 너(재미나이)가 먼저 판단해줘.

그 후, 가장 적절한 항목 1개를 선택하고

아래 3단 구성에 맞춰 자기소개서 문장을 완성해줘.

※ 사용자는 항목 번호를 선택하지 않음.
※ 재미나이가 “경험 분석 → 항목 매칭 → 최적 항목 선택 → 3단 구성 글 작성”까지 수행.

──────────────────────────────

[재미나이의 처리 절차]

1. 입력된 모든 경험을 검토

2. 각 경험이 어떤 항목에 적합한지 내부적으로 판단

3. 그중 자기소개서 항목으로 가장 강력하게 작성 가능한 경험 1개 선택후 작성

4. 추가적인 이야기가 필요하면 사용자에게 피드백을 해주고 항목을 더 작성 할 수 있게 함.

5. 아래 3단 구조에 따라 해당 항목의 자기소개서를 완성

──────────────────────────────

[자기소개서 2단 구성 – 모든 항목 공통 적용]

1. 사건 → 행동 → 배운 점(또는 능력)

STAR 기반

사건은 반드시 1개만 사용

“상황 → 문제 → 행동 → 배운 점(능력)” 순서로 자연스럽게 작성

단. 주석은 넣지 말기

2. 지원 회사에서의 기여 방식(구체적)

추상적 표현 금지

‘어떤 역량을 어떤 방식으로 적용할지’를 실제 업무 기준으로 구체적으로 작성


──────────────────────────────

[작성 규칙 – HR 관점 최적화]

1. 사용자 경험만 사용하며, 새로운 사실은 절대 넣지 말 것.

2. HR이 선호하는 ‘근거 → 결론’ 구조로 단단하게 작성.

3. 추상적·감정적·장식적 문장 최소화.

4. 안전·품질·정확성·재발방지·협업·관찰력 등 실무 중심 가치 반영.

5. STAR 구조를 자연스럽게 활용.

6. 기본 분량은 항목 당 8~12줄.

7. 선택된 항목 1개당, 에피소드는 반드시 1개만 사용.

8. 항목7(성격의 장단점)은 장점 1개 + 단점 1개 작성.

9. 항목 제목을 쓰고 아래에 경험 채워넣기(사용자가 선택한 항목은 무조건 들어가야함)

10. 선택된 항목들을 차례대로 숫자를 매겨서 보기 좋게 정갈하게 배열.
──────────────────────────────

[재미나이 문체 패턴 제거 규칙]

1. 동일 문장 구조 반복 금지.
2. 문장 시작을 "저는"으로 반복하지 말 것.
3. 아래 표현 사용 금지:
“~경험을 바탕으로 기여할 수 있습니다.”
“이러한 경험은 제가 ~하는 데 도움이 되었습니다.”
“저는 ~~한 사람입니다.”
4. 단문·중문·원인→행동형 등 다양한 문장 패턴을 섞어서 자연스럽게 구성.
5. 안전·정확성·품질 등 단어 반복 시 문장 구조를 조정해 자연스럽게 변형.
6. 기여 문장은 반드시 실제 업무 적용 방식으로 구체화할 것.
